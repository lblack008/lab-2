# Практическая работа №2. Прототип бесконечного раннера 

Проект представляет собой бесконечный раннер. Игрок может перепрыгивать препятствия и отстреливать врагов. При столкновении с ними игрок умирает и уровень начинается заново.
Взаимодействие объектов между собой реализовано через слои и маски коллизии.

## Иерархия проекта

### DamagingObject 
DamagingObject (унаследован от Area2D) - базовый класс для всех объектов, с которыми сталкивается игрок. 
Как только игрок с ними сталкивается - он умирает и игра начинается сначала. От этого класса наследуются следующие подклассы:

    1. Enemy - этот класс содержит в себе шаблон для всех врагов игрока.
    Основные поля - здоровье, получение урона от игрока и смерть. 
    От Этого класса наследуются 2 других класса: 
        1.1. Bat - летучая мышь. Появляется на случайной высоте, двигается по синусоиде. Умирает от одного попадания пули игрока по ней.
        1.2. Zombie - зомби. Появляется на земле и движется на игрока. Умирает от 3-х попаданий пуль игрока.
    2. Obstacle - класс для всех объектов, которые нельзя уничтожить. Нельзя убить с помощью пуль, однако, при попадании в эти объекты пули удаляются.
    От класса наследуется следующий класс:
    2.1. Rock - камень. Движется на игрока, находится на земле. Через него необходимо перепрыгивать, иначе игрок умирает.

## Структура сцен проекта

    1. Field - главная сцена игрового поля. Содержит землю, задний фон, таймер спавна и PackedScene для генерации врагов (зомби, летучих мышей и камней).
    2. Player - сцена игрока. Отвечает за прыжки и обработку ввода (чтобы стрелять и выходить из игры).
    3. Bullet - сцена пули. Пуля летит вправо, попадая в DamagingObject либо уничтожается, либо наносит урон врагу и тоже уничтожается. Если пуля не попала на какой-то объект, то при выходе с игрового поля она уничтожится.
    4. Zombie - сцена зомби. См. п. 1.2. иерархии проекта.
    5. Bat - сцена летучей мыши. См. п. 1.1. иерархии проекта.
    6. Rock - сцена камня. См. п. 2.1. иерархии проекта.
